# VideoTube - Backend API

## Project Overview

**VideoTube** is a YouTube clone designed as a comprehensive video-sharing and social media platform. The project provides RESTful API endpoints for video management, user interactions, and social networking capabilities, offering a feature-rich backend for web and mobile applications.

## Features

### 1. **User Management**

-   User registration, login, and authentication
-   Profile management (custom avatars and cover images)

### 2. **Video Management**

-   Video upload, update, and deletion
-   Manage video metadata (title, description, etc.)

### 3. **Social Interactions**

-   Commenting on videos
-   Tweet-like short posts
-   Like/dislike system for videos, comments, and tweets

### 4. **Content Organization**

-   Playlist creation and management
-   Add/remove videos from playlists

### 5. **Analytics and Dashboard**

-   Channel statistics and video performance metrics

### 6. **Subscription System**

-   Subscribe/unsubscribe to channels
-   Manage subscriptions and subscribers

### 7. **Watch History**

-   Track and retrieve user watch history

### 8. **Search and Discovery**

-   Search for videos, playlists, and user profiles
